# Contributing

Thank you for looking. **Pull requests are not accepted yet**: how outside contributions are
signed off (a DCO or a CLA) has not been decided, and code cannot be merged until it is. This
file will say so when that changes.

What helps right now:

- **Bug reports** as GitHub issues: what you did, what you expected, what happened, and the
  version (image tag). Logs are welcome — check them for tokens and hostnames first.
- **Ideas and questions** as GitHub issues.
- **Security problems** go to security@shorthop.io instead — see [SECURITY.md](SECURITY.md).

To run Shorthop from source, see [Development](docs/development.md).
